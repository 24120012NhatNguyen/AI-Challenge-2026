# Inference using OpenCLIP, Nomic and Faiss index
---

## 1. OpenCLIP 
Use OpenCLIP with another variant of CLIP model: ViT-L14, ViT-gopt-16-SigLIP2-384 model.
Embedding size is 768 with ViT-L14 model and 1536 with ViT-gopt-16-SigLIP2-384 model.

## 2. Nomic
Use Nomic with the Nomic-Embed-Vision model.
Embedding size is 768.

## 3. Faiss index
Use Faiss index to store and retrieve embeddings.
